🆕 (2026-09-15) เขียนไฟล์นี้ตอนจัดระเบียบ `output/` หลังเจอว่ามีโฟลเดอร์ทดสอบว่างเปล่าสะสมไป 50 อัน
(ลบไปแล้ว) + ไฟล์หลวมๆ ที่ root ปนกันมั่วระหว่างของจริง/ของทดลอง/ไฟล์สำรอง — ไฟล์นี้อธิบายกฎการตั้งชื่อ
ที่ใช้ตั้งแต่นี้ไป กันงงซ้ำอีก

## กฎการตั้งชื่อ

| ชื่อ | คืออะไร |
|---|---|
| `_checkpoints/` | cache ที่ใช้ซ้ำได้ข้ามรอบ/ข้ามหัวข้อ (เช่น embedding ของแคตตาล็อกสินค้า 10,622 SKU) **ห้ามลบ** เว้นแต่ตั้งใจบังคับ re-embed ใหม่ทั้งหมด (เสีย NVIDIA API จริง) |
| `_backups/` | ไฟล์สำรอง/รอบที่ไม่สมบูรณ์ที่เก็บไว้เผื่อย้อนดู ไม่ใช่ผลรันที่ใช้งานจริง ลบทิ้งได้ถ้าแน่ใจว่าไม่ต้องใช้แล้ว |
| `<slug ของหัวข้อ>_<วันเวลา>/` เช่น `beauty_and_personal_care_20260911_162349/` | ผลรัน**เต็ม 1 รอบจริง** ผ่าน `main.py` — ทุกไฟล์ในนี้มาจากหัวข้อ/รอบเดียวกันเสมอ |
| `legacy_flat_before_run_ids/` | **ชุดข้อมูล "legacy"** จากก่อนระบบแยกรอบจะมีถึง (ก่อน 2026-09-11) + ไฟล์ที่เขียนทับมาที่ชุดนี้ทีหลัง (เช่น brand coverage ถึง 2026-09-15) — เป็นรอบจริงรอบหนึ่งเหมือนกัน 🆕 (2026-09-16) **ย้ายจากที่เคยกองแบนๆ ที่ root มารวมเป็นโฟลเดอร์เดียวแล้ว** (29 ไฟล์ + 4 โฟลเดอร์ step5) `main.py` โหมด 2 มองเห็นเป็นรอบปกติทั่วไป ไม่ต้องใช้ทางพิเศษอีก (sentinel `TREND_RUN_ID=_legacy_flat` ยังเหลืออยู่ใน `bootstrap.py` แต่ไม่มีอะไรเรียกใช้แล้ว) |
| ไฟล์หลวมๆ ที่ root | **ไม่ควรมีอีกแล้ว** — root เก็บแค่ `README.md` (ไฟล์นี้) + โฟลเดอร์ `_*` + โฟลเดอร์รอบรัน ถ้าเห็นไฟล์ `phase*.json` โผล่มาแบนๆ ที่ root แปลว่ามีสคริปต์รันโดยตั้ง `TREND_RUN_ID=_legacy_flat` (หรือแก้ `OUTPUTS` เอง) — ย้ายเข้าโฟลเดอร์รอบให้ถูกต้อง |

## โฟลเดอร์ขึ้นต้นด้วย `_` ทั้งหมด = "ไม่ใช่ผลรัน"

ตามธรรมเนียมนี้ `main.py`'s โหมด 2 (ค้นหาแบรนด์จากรอบที่มีอยู่แล้ว) จะข้ามโฟลเดอร์ที่ขึ้นต้นด้วย `_`
ทุกอันโดยอัตโนมัติเวลา list รอบให้เลือก (ดู `_list_available_runs()` ใน `main.py`) — ถ้าจะเพิ่มโฟลเดอร์
พิเศษประเภทใหม่ในอนาคต ให้ตั้งชื่อขึ้นต้นด้วย `_` เพื่อให้กฎนี้ครอบคลุมอัตโนมัติ ไม่ต้องแก้โค้ด

## ไฟล์ในชุด "legacy" ที่ติด `_MOCKUP`/`_STALE_...` ในชื่อ

บางไฟล์ในชุด legacy ตั้งชื่อบอกตัวเองไว้แล้วว่าไม่ใช่ของจริง (เช่น `phase2_all_streams_comparison_
MOCKUP.json`, `phase2_news_intl_stream_result_STALE_PREFIX_HALLUCINATED.json`) — เป็นไฟล์ทดลอง/
ตัวอย่างจากตอนพัฒนา ไม่ใช่ผลลัพธ์จริงที่ pipeline ใช้ **อย่าใช้ไฟล์เหล่านี้เป็นข้อมูลอ้างอิง**

## ✅ โฟลเดอร์ `adhoc_*` ว่างเปล่า — แก้ที่ต้นเหตุแล้ว (2026-09-16)

`bootstrap.py` สร้างโฟลเดอร์ `OUTPUTS` ทันทีตอน import (`OUTPUTS.mkdir(...)`) แม้ยังไม่มีอะไรเขียนลงไป
เลย — รันสคริปต์เดี่ยวๆ หรือรันเทสโดยไม่ตั้ง `TREND_RUN_ID` จะได้โฟลเดอร์ `adhoc_<timestamp>/` ว่างใหม่
ทุกครั้ง (สะสมไป 72 อันในรอบที่สอง ลบทิ้งแล้ว) ตอนนี้ `bootstrap.py` ลบให้เองตอนจบโปรเซส ด้วย `atexit` +
`os.rmdir()` — เฉพาะโฟลเดอร์ชื่อ `adhoc_*` ที่ยังว่างจริงเท่านั้น มีไฟล์อยู่ข้างในแม้แต่ชิ้นเดียวจะไม่แตะ

**ทำไมไม่ย้ายไปสร้างตอนเขียนไฟล์จริงแทน:** มีสคริปต์ 25 ไฟล์ที่ `open(OUTPUTS / "...", "w")` ตรงๆ โดยไม่
`mkdir` เอง (มีแค่ 9 ไฟล์ที่เรียก `prompt_run_config()` ซึ่งพอจะแทรกจุดสร้างได้) ถ้าเอาการสร้างตอน import
ออกจะไปพังตอนเซฟผลท้ายรอบ = เสียทั้งรอบรันที่ใช้เวลาเป็นชั่วโมง
