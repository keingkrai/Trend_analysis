## เป้าหมายหลัก
เพิ่มชั้น 3-4 ในการรวมผลพยากรณ์:
```
ชั้น 1: (คีย์เวิร์ด × กลุ่ม)   ← มีแล้วใน trend_final.py
ชั้น 2: .mean() → กลุ่ม        ← มีแล้ว
ชั้น 3: .mean() → หมวด         🆕
ชั้น 4: .mean() → ภาพรวม       🆕
```

> [!danger] ใช้ `.mean()` เท่านั้น ห้าม `.sum()`
> เคยพังมาแล้วตอนรวมชั้นคีย์เวิร์ด→กลุ่ม: บวก z-score ของ ~18 คีย์เวิร์ดทำให้ทะลุเกณฑ์
> ตัดสิน (0.8/0.2/-0.2) แทบทุกกลุ่มไม่ว่าเทรนด์จะแรงจริงหรือไม่
