# ①-⑤ สาย Search (Google Trends)

ใช้แทน 3 สายเดิม Paper / Social / News ตั้งแต่ 2026-10-27 — เริ่มจากสิ่งที่คนค้นเพิ่มขึ้นจริงในทุกหมวดของ Google โดยไม่ใส่หัวข้อตั้งต้น
แล้วค่อยโยงหาความต้องการเครื่องสำอาง (ที่มา: การทดลอง `output/_experiments/open_talk_20261027/`)

## ขั้นตอน (`search_stream.py`)

1. **ดึงคำค้นที่กำลังขึ้นรายหมวด** (`rising.py`) — `RELATED_QUERIES` ของ Google Trends ระบุแค่หมวด (`cat`) ไม่ใส่คำค้น ช่วง 12 เดือนล่าสุด
   - ค่าเริ่มต้น: ไทย + ทั่วโลก ทุกหมวดระดับ 1-2 (313 หมวด, ~600 search)
   - cache รายเดือนที่ `output/_checkpoints/search_rising/<YYYY-MM>/` — รอบอื่นในเดือนเดียวกันไม่เสียโควตา
   - หยุดก่อนเริ่มถ้าโควตาจะเหลือไม่พอให้ ⑦ / คีย์ที่ติดจำกัด 250 search/ชั่วโมง พักไว้แล้วใช้คีย์ถัดไป
2. **LLM จัดหัวข้อ** (`themes.py`) — รวมคำค้นของแต่ละหมวดเป็นหัวข้อ 2 รอบ (LLM ตอบเป็น id ของคำค้น จำนวน/ประเทศนับจากข้อมูลจริง)
3. **LLM โยงเครื่องสำอาง** — 7 ทางโยงที่ตั้งไว้ล่วงหน้า (ความงามตรงๆ · สภาพแวดล้อม · ร่างกายและสุขภาพ · โอกาสและเทศกาล ·
   กิจกรรมและไลฟ์สไตล์ · ส่วนผสมข้ามหมวด · วัฒนธรรมและลุค) + หมวดสินค้า Euromonitor L2 ชุดเดียวกับ ⑫
   - กฎ: หัวข้อที่โยงได้ต้องอ้างคำค้นตัวอย่างอย่างน้อย 1 คำ ไม่งั้นนับเป็นไม่โยง
4. **คัดด้วยกฎตัวเลข** — ขึ้นกี่พื้นที่ > มีไทย > จำนวนคำค้น > สัดส่วน Breakout แล้วให้ LLM รวมหัวข้อที่เป็นความต้องการเดียวกัน
   และเขียนโปรไฟล์เทรนด์ฝั่งความงามจากคำค้นจริงเท่านั้น + คำค้นฝั่งความงามที่ ⑦ ใช้วัดการเติบโต
5. **จุดตรวจ** — `phase2_search_candidates.csv` (คอลัมน์ `keep`: 1 = ใช้, 0 = ตัดทิ้ง) รันแบบโต้ตอบจะหยุดให้แก้ก่อนไปต่อ
6. **เขียนผล** — `phase2_search_stream_result.json` รูปแบบเดียวกับผลของสายเดิม (`trends` / `keywords` / `report` / `documents`)
   + `search_meta` → ⑦ เป็นต้นไปทำงานต่อได้เลย

## ค่าตั้ง (env)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `TREND_SEARCH_GEOS` | `TH,WW` | พื้นที่ที่ดึงทุกหมวดระดับ 1-2 (WW = ทั่วโลก) |
| `TREND_SEARCH_GEOS_TOP` | ว่าง | พื้นที่ที่ดึงเฉพาะหมวดใหญ่ 25 หมวด เช่น `US,JP,KR` (+25 search ต่อพื้นที่) |
| `TREND_SEARCH_TOP_K` | `20` | จำนวนเทรนด์สูงสุดที่ส่งให้ ⑦ (~5-6 คีย์เวิร์ดต่อเทรนด์) |
| `TREND_SEARCH_REVIEW` | `1` | `0` = ไม่หยุดที่จุดตรวจ |

งานกลางทางเก็บที่ `<รอบ>/search_stream_work/` (หัวข้อ ผลโยง โปรไฟล์) — รันขั้นนี้ซ้ำในรอบเดิมใช้ต่อ ไม่ถาม LLM ซ้ำ
ลบไฟล์ในนั้นถ้าต้องการให้ LLM ทำใหม่

## ข้อจำกัดที่รู้

- หมวดที่ Google ใส่ให้คำค้นปนมาก (ฟุตบอลโลก ละคร AI ขึ้นในหลายหมวด) — ขั้นจัดหัวข้อจัดตามเนื้อหา ไม่ตามหมวด
- โปรไฟล์เทรนด์มาจากคำค้นอย่างเดียว บางกว่าสายเดิมที่อ่านบทความทั้งชิ้น — ส่วนผสมที่คำค้นไม่บอกเว้นว่าง
- หัวข้อเทศกาลมักขึ้นทุกปีตามฤดูกาล (มีปีในคำค้น) ยังไม่มีกฎแยกเทศกาลออกจากเทรนด์ใหม่
- ไม่มีคะแนน Longevity และไม่มี "แหล่งที่ยืนยัน 3 แหล่ง" — รายงาน ⑯ แสดง "คำค้นขึ้นใน" + ทางโยงแทน
