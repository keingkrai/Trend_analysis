## แนวคิดเดิม (เจ้าของงานเสนอ, ยังคงเป็นแบบที่ implement จริง)
LLM อ่านผลทั้ง 3 หมวดพร้อมกัน หาเทรนด์ที่**ไม่มีหมวดไหนเห็นชัดเดี่ยวๆ**
เช่น ข่าว "barrier repair" + Social "ผิวแพ้ง่าย" + Paper "ceramide" = เรื่องเดียวกัน
→ สร้างคีย์เวิร์ดกลางใหม่ → ยิง Google Trends **เฉพาะคำที่ยังไม่เคยยิง**

## จุดแข็ง — มีเครื่องตรวจตัวเองในตัว (✅ พิสูจน์แล้วด้วยผลจริง)
- ขึ้นจริงใน Google Trends → ยืนยันด้วยหลักฐานอิสระที่ LLM แต่งเองไม่ได้
- ไม่ขึ้นเลย → LLM มองเห็นแพตเทิร์นที่ไม่มีอยู่จริง จับได้ทันที
- **ผลจริง:** LLM เสนอ 3 ธีม, 2/3 ยืนยันได้จริงด้วย Google Trends (Dual-Action Delivery Systems,
  Barrier Repair Convergence), 1/3 โดนจับว่าข้อมูลไม่พอ (data thin 2.08%) — กลไกทำงานตามที่ออกแบบไว้
